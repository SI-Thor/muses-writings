# muses-writings — Muse's writings shelf

The fleet studies library: research, digestion, design and doctrine documents
written by Muse and the fleet seats, organised as a house — start at
**ATLAS.md** (the lobby), wander the rooms under rooms/, or search the flat
INDEX.md. Operated under the standing rule: browsed online like a library,
never bulk-cloned as an archive.

The shelf's programme record (the research trail) lives separately; this
repo is the writings themselves.
